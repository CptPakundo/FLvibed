# FLvibed's docs

This folder holds about a hundred files; most are working notes from FLvibed's development. These are the ones to start
with. The project's front page is the [README](../README.md).

## 🎮 If you play

- 🌟 [The Feature Tour](https://claude.ai/artifact/4v4dXbB5GTVt1URowFtSvN): everything FLvibed does, with in-game pictures and the full button layout (offline copy: [spec/index.html](spec/index.html)).
- ⚙️ [SETTINGS.md](SETTINGS.md): every setting with its range, default and what it does.
- 🆕 [RELEASE_0.4.6.md](RELEASE_0.4.6.md): the latest release's notes, issue by issue, with what was and was not verified.
- 📜 [CHANGELOG.md](../CHANGELOG.md): every release's changes in a player's words.
- 🌐 [MULTIPLAYER.md](MULTIPLAYER.md): FLvibed on a server, and what server hosts can allow.
- 🧩 [MOD_COMPATIBILITY.md](MOD_COMPATIBILITY.md): other mods and plugins, and how FLvibed gets along with them.

## 🛠️ If you build or mod

- 🏗️ [ARCHITECTURE.md](ARCHITECTURE.md): how FLvibed is built, its layers and modules, and how to add a module.
- 🧪 [TESTING.md](TESTING.md): how changes are tested in game; the harness itself is in [HARNESS.md](HARNESS.md).
- 🧠 [FREELANCER_RE.md](FREELANCER_RE.md): verified facts about the game's code and data, for anyone writing hooks.
- 📚 [kb/README.md](kb/README.md): the game knowledge base, how Freelancer plays, by topic and mission.
- 🧰 [tools/README.md](../tools/README.md): the build, deploy and game-data tools.

Each feature also keeps its own notes beside its code:

- 🤖 Autopilot: [modules/autopilot/docs/AUTOPILOT.md](../modules/autopilot/docs/AUTOPILOT.md)
- 🎮 Controller: [modules/controller/docs/BINDINGS.md](../modules/controller/docs/BINDINGS.md)
- 🛰️ HUD 2: [modules/hud/docs/UI_HUD2.md](../modules/hud/docs/UI_HUD2.md)
- 💬 Subtitles: [modules/subtitles/docs/DISPLAY_PLAN.md](../modules/subtitles/docs/DISPLAY_PLAN.md), and how the subtitle text is made: [subtitles/review/docs/REVIEW_PROCESS.md](../subtitles/review/docs/REVIEW_PROCESS.md)
- 🌐 The server plugin: [server/flhook/README.md](../server/flhook/README.md)
