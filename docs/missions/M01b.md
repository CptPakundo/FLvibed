Source: `Install\Freelancer HD Edition\DATA\MISSIONS\M01b\m01b.ini` (2566 lines), `npcships.ini` (ship archetypes only, no triggers). The folder has no base scene files (`m0*_offer/reoffer/nrml.ini`): only `.thn` space scenes (`M01_space_enter.thn`, `m01b_king_01.thn`, `m01b_11.thn`, plus `m01b_01/02/03.thn`, not called by the script). Read-only analysis; nothing in the game was changed.

**Conventions**
- Line numbers are the ones the Read tool prints (the first line `[Mission]` is 0, so an editor shows every number +1). Mine start at 1 for the first line of the file as printed by Read.
- `->` = `Act_ActTrig`. `DeactTrig` = `Act_DeactTrig`. `+lines` = the length of comm lines, here turned into seconds with the `sec` column of `subtitles\data\subtitles.tsv` (ids are lower case there).
- `Cnd_Timer` values add up along a chain. A comm started with `Act_SendComm` does not delay the next `Act_ActTrig` in the same trigger; only `Cnd_CommComplete` waits for the line.
- Triggers without `InitState` are inactive until something activates them (only `tr_start` is `InitState = ACTIVE`, line 855).
- `Cnd_WatchTrigger = X, ON` is read here as "X is still armed" (not fired yet) and `off` as "X has already fired or was deactivated". This fits `wt_plat1alive` (2214: platform still alive -> destroy it) and the formation watchers (see step 2). **Uncertain** (engine behaviour, not in the file).
- Verified in M01a: nags (`Act_NagDist*`) escalate to the FAIL text given as their string id. Here every nag string is a "Mission Failed" text (checked below), so every nag in this mission is a fail path. The script gives no nag timing (engine-defined) and no `Act_ChangeState` for them. Nags are therefore listed as **nag fails**.
- String ids resolved from `research\strings\resources.tsv` (titles only).

**Verified end to end (18 Oct 2026, harness + autopilot, no god mode):** `controller\tools\missions\M01b.ps1` from
the campaign save `Save5f61.fl` (docked at Pittsburgh) to "Mission Result: Success". Facts learned: the mission
locks maneuvers while the player flies in Epsilon's formation (the combat autopilot is refused until
`LockManeuvers false` at the King's arrival - `Invoke-FLMissionFight` waits for it); the player must close on the
fight (wave 1 fights the King ~9 km from where the formation broke up; 5 km from the King = nag 22195); the waves
come in two steps (the combat autopilot ends between them; `Invoke-FLMissionFight` restarts it); the prison ship
survived at 1 % hull. Uncertainty 6 resolved: the mission starts docked with no offer popup; launching works.
