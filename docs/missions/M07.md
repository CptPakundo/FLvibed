# M07 (Br04 Leeds / Bw08 Cali / Ku03 Kyushu) - tester runbook

Source: `Install\Freelancer HD Edition\DATA\MISSIONS\M07\m07.ini` (3072 lines, 203 triggers), `npcships.ini`, base scenes `m007_s037a_br04_01_offer.ini`, `m007_s037d_br04_01_reoffer.ini`, `m007_s038xa_bw08_01_nrml.ini`, `m007_s038xb_bw08_01_nrml.ini`, `m007_s039x_ku03_01_nrml.ini`. Read-only analysis.

**Conventions**

- Line numbers are 1-based (as an editor shows them).
- `->` = `Act_ActTrig`. "complete" = `Cnd_CommComplete` (the line finished playing). `+lines` = dialogue time; here it is turned into seconds with the `sec` column of `subtitles.tsv` (the sum is written as `= n s`).
- Ids are resolved from `research\strings\resources.tsv`; titles only. For `rep_inst` / `navmarker` objectives the script gives two ids (title / text); the title is quoted.
- Trigger names are in `code`. Every one of the 203 triggers is named in this file.
- **No popups** (`Act_PopUpDialog`) exist in this script. The only pausing UI is the Leeds offer, the base scenes and the mission briefing the game itself shows at launch (**Uncertain**: M01a showed one; the script is silent).
- Nags: every nag text id used here (23350-23382) is a "Mission Failed. You failed to ..." / "You fled the battle" text, i.e. **a FAIL text**. M01a verified that nags escalate to FAIL. So every nag below is a fail path. The script gives **no timer** for any nag (the engine decides); the radius is given only for the `position` nags.
- "Friends" = Juni, Sinclair, Quintaine (label `lbl_friends`), later Tobias and his two escorts, later Razor-One and wing.
