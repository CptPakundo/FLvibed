# M04 (Li01 "Escape from Liberty" -> Iw03 -> Br04 Leeds) - tester runbook

Source: `Install\Freelancer HD Edition\DATA\MISSIONS\M04\m04.ini` (4890 lines, 274 triggers, read in full), `npcships.ini`
(ship loadouts only, no logic), base scenes `m004_s019a_li01_01_offer.ini` / `m004_s019d_li01_01_reoffer.ini`
(Manhattan, Cityscape, character `drake`), `m004_s020x_li01_04_nrml.ini` (Benford bar, Van Pelt),
`m004_s021x_br04_01_nrml.ini` (Leeds Equipment, Tobias). Read-only analysis; nothing was run in the game.

**Conventions** (as in M01a, `README.md`)

- Line numbers are 1-based (as an editor shows them; +/- 1 where a trigger's header line was cited). Comm events carry `first=0x<Get-FLHash of the DX_ id>`, so every cited DX_M04_nnnn line is a harness signal. For a trigger I cite
  the line of its `nickname`.
- `->` = `Act_ActTrig`. `+lines` = comm time. Line seconds come from the `sec` column of `subtitles\data\subtitles.tsv`
  (DX_M04_* ids, listed per chain below). Timers are `Cnd_Timer` seconds.
- String ids are resolved from `research\strings\resources.tsv` (title only). **No `Act_PopUpDialog` exists in M04**:
  there are no story popups. Blockers are the base scenes, the briefing after accept (assumed as in M01a, **Uncertain**),
  space cutscenes (`Act_CallThorn`) and player freezes (`Act_PobjIdle`).
- Nags: M01a verified that `Act_NagDist*` escalate to FAIL. In M04 every nag text is a "Mission Failed" text.
  Nag ids 22750, 22755, 22770 are also used by `Act_ChangeState = FAIL` here. Nag ids 22760, 22765, 22775, 22780 are
  **not** used by any `ChangeState` in this file, so whether they fail the mission is **Uncertain** (the text says
  "Mission Failed"; treat them as failing). The nag timing (how long) is not in the file.
- `Act_Invulnerable = X, true, false, 0.9` (last number) is undocumented (see M01a uncertainty 5). It is on Juni nearly
  the whole mission: Juni is hard to kill but not safe; her death is a FAIL.
