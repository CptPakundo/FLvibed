# M09 (Ku06 / Ku07, "Attacking Tekagi's Fortress") - tester runbook

Source: `Install\Freelancer HD Edition\DATA\MISSIONS\M09\m09.ini` (2135 lines, 122 triggers), `npcships.ini`, base scenes `m009_s050a_ku06_01_bar_offer.ini`, `m009_s050d_ku06_01_bar_reoffer.ini`, `m009_s051xa/xb/xc_ku07_01_nrml.ini`, `m009_s052x_ku06_01_nrml.ini`. Read-only analysis.

**Conventions:** line numbers are 1-based (as the Read tool prints them). `->` = `Act_ActTrig`. Times are seconds. `+lines` = comm line durations, taken from the `sec` column of `subtitles\data\subtitles.tsv`. Text ids are resolved from `research\strings\resources.tsv` (titles only). Triggers without `InitState` start inactive. Only `tr_offer` (966) is `InitState = ACTIVE`. M09 has no `Act_PopUpDialog` and no `Act_StartCutscene`: there are no pausing popups in this script.

**Nags are fails.** Every nag in this file (`Act_NagDistTowards`, `Act_NagDistLeaving`) carries a text id that is exactly a "Mission Failed. ..." text (23750-23793). As verified in M01a, a nag that runs out escalates to FAIL with that text. So each nag below is a fail path. The nag timing is engine-defined, not in the file (**Uncertain**, no seconds given).

**Start:** Kyoto Base (`Ku06_01_base`, Ku06 Kyoto system), bar. Character Ozu (Blood Dragon) offers the job (autoplay scene `s050a`). M08 hands over implicitly: this file has no hand-over trigger; the offer is armed by `tr_offer` (966) from the start.

**End:** SUCCEED when the player leaves the cityscape room of Kyoto Base after the return (`mission_completed`, 2107-2134). Player is then in Kyoto Base, +10000 credits.
