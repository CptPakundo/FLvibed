**Conventions** (same as M01a)

- Line numbers are 1-based (the first line `[Mission]` is line 1; the editor and the Read tool agree). `->` = `Act_ActTrig`.
- Times are seconds. `+lines` = the duration of comm lines, taken from the `sec` column of `subtitles\data\subtitles.tsv` where I could add it up. Gaps between lines are unknown.
- **Nags equal FAIL texts.** Every nag in M11 uses a "Mission Failed. You failed to ..." text id (24157-24197). M01a verified in game that nags escalate to that FAIL. So treat every nag below as a FAIL path. **Uncertain:** how long a nag waits before it fails. The file gives no time.
- Nag parameters as written: `NagDistTowards = OBJ|POS, nick, ship, target, ids, dist, flag`; `NagDistLeaving = nick, ship, target, ids, dist, flag`. I read `dist` as "the player must get within `dist` of the target" (Towards) or "must stay within `dist`" (Leaving). With `dist = 1` the Leaving nag means "must enter the target" (hole, gate, dock). **Uncertain** (interpretation).
- `Act_Invulnerable = x, true, false, 0.9`: last argument undocumented (see M01a). `Act_PobjIdle` has no un-idle in this file.
- No `Act_PopUpDialog` exists in M11. No popup pauses the game. The briefing (`NavMapContinueButton`) is the engine's mission briefing on launch (**Uncertain**, not in the script).
- NN log entries (`Act_NNIds`, HISTORY): 31100, 31105, 31110, 31115, 31120. They show as `nn-message` events (**Uncertain**).

**Start**: Battleship Osiris (base `Li04_06_base`, system Li04), room `Deck2`. Orillion offers the mission in the scene `s067a_offer` (characters Orillion, King, Juni; autoplay). Objective before accepting: `mlog_pre` 24010 "Meet Orillion on the Launch Deck of the Battleship Osiris". Handover from M10: M10 enters `Li04_06_base` at `m10.ini` line 6574 (**Uncertain** how it ends; not read).
