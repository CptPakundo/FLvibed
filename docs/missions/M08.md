# M08 (Ku01 / Ku06 story mission 8) - tester runbook

Source: `Install\Freelancer HD Edition\DATA\MISSIONS\M08\m08.ini` (1191 lines), `npcships.ini`, base scenes `m008_s045a_ku01_05_offer.ini`, `m008_s045d_ku01_05_reoffer.ini`, `m008_s046x_ku06_01_nrml.ini`. Read-only analysis.

**Conventions**

- Line numbers are 1-based, as the Read tool prints them for `m08.ini`.
- `->` = `Act_ActTrig`. Times are seconds. Line durations come from the `sec` column of `subtitles\data\subtitles.tsv`. Gaps between lines are not known, so dialogue totals are lower bounds.
- Comm events: `comm ... first=0x<hash>` where the hash is `Get-FLHash` of the DX_ id (verified). Below, a comm is named by its DX_ id.
- Nag texts: the file has no `ChangeState` for nag ids. Per the verified M01a note, `Act_NagDistTowards` / `Act_NagDistLeaving` escalate to FAIL with the nag text. The nag ids below are therefore real FAIL texts (all nag texts equal FAIL-style texts). The file gives no nag timing (the numbers in nag actions look like distances), so **no fail time can be stated for nags**. **Uncertain.**
- Nag argument reading (inference, **Uncertain**): `NagDistTowards POS, name, speaker, x, y, z, text, dist` = the player must move towards the position. `NagDistLeaving name, speaker, object, text, dist` = the player must not leave `dist` from the object. `Ozu`/`Juni` are the speakers.
- Triggers without `InitState` are inactive until `->`. Only `key_offer` (411) starts active.
- Solar nicknames usable by `Set-FLTarget` / `Start-FLDock`: `Ku01_05` (base solar, `Ku01\ku01.ini`), `Ku06_01` (`Ku06\ku06.ini`), `Ku01_to_Ku04_hole`, `Ku04_to_Ku06_hole`, `Ku01_Trade_Lane_Ring_32`. Script ships: `Transport1`, `hostile_platform1`, `hostile_platform2`, `rh_1`..`rh_12`.

**Mission**: Honshu strike with Ozu (Blood Dragon). Fly Ku01 -> Trade Lane -> jump hole to Ku04, destroy the weapon platforms and Kusari forces, protect Tekagi's transport, jump to Ku06, dock.

**Start**: the player is in space or at base after the previous mission (M07 hand-over **Uncertain**, not in this file). `key_offer` (408) is active from load: objective `land` (23410 "Meet Juni in the Shinagawa Station Bar"), unlocks docking at `Ku01_05` for the player (415), NN path (416, 430), and in space plays Juni's ether call `DX_M08_0000_JUNI` (6.47 s, 437-441). The offer is in base `Ku01_05`, room `Bar`, character Juni (offer scene file).

**End**: SUCCEED when the player leaves room `Cityscape` of base `Ku06_01` (`entering_bar`, 1088-1092). The base scene `m008_s046x` (autoplay, `relocate_player = Bar`) moves the player to the Bar, so the player ends in Ku06_01 Bar.
