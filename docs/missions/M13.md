# M13 (St01 / St03 / St03b / Li01, the final story mission) - tester runbook

Source: `Install\Freelancer HD Edition\DATA\MISSIONS\M13\m13.ini` (2812 lines), `npcships.ini` (ship archetypes only, no
logic), the base scenes `m013_*.ini` and `m13_opensp_normal.ini` / `m13_opensp_pirate.ini`. Read-only analysis.

**Conventions**

- Line numbers are the ones the Read tool prints (1-based). `->` = `Act_ActTrig`. `DeactTrig` = `Act_DeactTrig`.
- Times are seconds. `Cnd_Timer` values are added up along a chain. Spoken lines (`DX_M13_nnnn_SPEAKER`) are turned into
  seconds with the `sec` column of `subtitles\data\subtitles.tsv` (`Act_StartDialog` plays its lines one after the other;
  I add them up, without gaps). Ids such as `24414` are resolved from `research\strings\resources.tsv` (titles only).
- Triggers without `InitState` are inactive until something activates them (`key_offer` is the only `InitState = ACTIVE`, 1196).
- Nags (`Act_NagDistTowards` / `Act_NagDistLeaving`) **escalate to FAIL** (verified in M01a). Here every nag text is
  a "Mission Failed ..." text, so they are failure texts, not hints (see "Nags" below).
- **Play time only counts from "T0 = launch into St01" (step 1).** The mission has no autosave except one (see Save points).

**Start:** Toledo, the Order base planet (`st01_01_base`, system St01). The player arrives with the previous mission
already done. The offer scene plays in the `trader` room (Orillion is the offering character, 1217-1221, scene
`m013_s072ab_st01_01_offer.ini` 2-5). Planetscape first plays `m013_s072aa` (Juni, `autoplay`, 1213), then the offer.

**End:** `the_end_end` (2514) `Act_ChangeState = SUCCEED` (2517). The player is then in **Manhattan (`li01_01_base`),
Cityscape**, after `Act_AdjAcct = 20000` (2511). The hand-over to free roam is described at the end of this file.

## What the two `m13_opensp_*.ini` files are (hand-over to free roam)

- They are **not** referenced by `m13.ini` and not by any other `.ini` in the install. Their names say "M13 open single player": `normal` and `pirate`.
  The HDE changelog (`CHANGELOG.md` 582-584) describes "optional no-story (open single player) modes": Normal = start on Manhattan with a basic loadout and a default
  reputation, Pirate = start on Rochester with a basic loadout and an inverted reputation. The installer data holds an `ENABLEOPENSP` switch. So these two
  files are the HDE's own "start a new game after the story" missions, not part of the story. How the game loads them (installer option, probably replacing the new-game mission) is **Uncertain**.
- Both files are one trigger `bse_initialize_init_li01` (`InitState = Active`, line 2) with the same layout as the M01a trigger of the same name:
  - normal: `Act_ForceLand Li01_01_Base` (6), `Cnd_BaseEnter Li01_01_Base` (7), `Cnd_SpaceExit` (8), `Act_SetShipAndLoadout ge_fighter, msn_playerloadout` (9).
  - pirate: the same with `Li01_13_Base` (6-7) and `msn_pirateplayerloadout` (9).
  - then about 90 `Act_LockDock ... unlock` lines (11-96: every jump hole, gate and dock ring, including the St01 ones and `osiris`), the reputation list (153-199) and `Act_GCSClamp = false` (201), and finally `Act_ChangeState = SUCCEED` (203).
  - normal reputation: Li01 / LSF / Li pirates `0.91 / 0.91 / 0.65`, the rest like `enter_bar` in `m13.ini` (2445-2492, same values, spot-checked). Pirate: the same list with the signs of the non-zero values inverted (Li groups `-0.91`, `-0.91`, `-0.65`; Corsairs / outcasts `+0.3`, `+0.65`).
- So the mission **ends immediately** (SUCCEED) after forcing a landing and setting ship, reputation and docks; the game then continues in free roam in Manhattan (or Rochester for pirates). This is the "no story" start.
- After the real M13: `enter_bar` (2440-2506) performs the same reputation reset and dock unlocking, and `the_end_end` SUCCEEDs in Manhattan Cityscape. So the story ends in the same state as the `normal` hand-over: free roam, Manhattan, dock locks open, +20000 credits.
- **Uncertain:** the mission list after M13 (`Content.dll` lists `Missions\M13\m13.ini` as the last one) and what the engine does after SUCCEED (a story-end flag in the save) are not in the files.
- Harness: free-roam fixtures `SaveC701` / `SaveC702` match the end state. A real post-M13 state needs the test above.
