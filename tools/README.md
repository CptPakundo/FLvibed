# FLvibed tools

Every tool resolves paths from its own location (`$PSScriptRoot`); run them by full path. PowerShell scripts only in
the PowerShell tool, never from Bash. Python tools run with the project's own interpreter
(`research\tools\ocr\.venv\Scripts\python.exe -I`; there is no system Python); JavaScript tools with Node.

## Parallel lanes (`lane.ps1`, 12 Nov 2026)
C++ work runs in up to three lanes at once (`..\docs\TESTING.md` "Parallel lanes"), each a git worktree beside the main checkout with its own branch, `build\`
folder, build lock and game test instance, merged into main one at a time and removed after its merge. Worktrees are made
and removed only with this tool (by hand, workers overwrote each other's scratch files, and a removal can follow the
`Install` junction into the shared install). When and how to use one: `..\docs\TESTING.md` "Parallel lanes".
| Command | What |
|---|---|
| `lane.ps1 new <name> -Instance <n> [-From <commit>] [-Owner <who>]` | Branch `lane/<name>` and the worktree `..\..\FLvibed-lane-<name>`; junctions to main's shared, git-ignored folders (`Install`, `research\Vanilla`, `repos`, `saves`, `tools` with the venv, `evidence`, `disasm`, every `research\experience` folder but `legs\`); `build\sdl3` copied; `scratch\` and `.lane\` (git-ignored); the instance reserved in `..\..\.claude\lanes.json`. Refuses a name, branch or instance taken, a running game there, logs written there in the last 30 min (`-Force`), named instances and `v11nightly`. Prints the lane's build, deploy, harness, net and lint commands |
| `lane.ps1 status` | Every lane: branch, ahead / behind main, verified tip, uncommitted files, size, a build running, its instance and whether a game runs there (and from where); worktrees that are not lanes, lanes missing from the registry or from git |
| `lane.ps1 sync <name>` | Rebases the lane on main; refuses uncommitted changes; on conflicts stops (the rebase left in progress) and names the files |
| `lane.ps1 verify <name> [-Passed 'nn_pages=<run>,classic_frames=<run>']` | Runs the unit tests, a release build (its `build_info.txt` must name the clean tip) and `module_lint.py --enforce` in the lane, records the named game-net runs (each written after the tip commit), and writes `.lane\verified\<commit>.json`: `lane`, `branch`, `commit`, `main` (main's tip then), `by`, `time`, `ok`, `checks` (`name`, `ran_by` lane.ps1 with `exit` / `seconds` / `detail`, or `declared` with `evidence`), `log` |
| `lane.ps1 merge <name> [-WhatIf]` | Fast-forwards main to the lane's tip, only when the lane is clean, rebased on main's tip and its marker passes that tip, and main has no uncommitted change in a file the lane changed; never pushes |
| `lane.ps1 remove <name> [-KeepBranch] [-Abandon] [-KeepScratch <folder> \| -DiscardScratch] [-WhatIf]` | Refuses commits main lacks (`-Abandon` first writes them, and any uncommitted change, to `research\stash_patches\lane-<name>\<time>\`), a game on its instance, a process or build in the worktree, a file open there, and files of its own (scratch, evidence written inside the lane) unless kept or discarded. Then: `.lane\` kept in main's research\experience\lanes, every reparse point removed as a link only with each target's file list compared before and after, `git worktree remove`, the branch deleted, the instance freed. `-WhatIf` prints the plan |
| `lane.ps1 adopt <name> -Instance <n>` | Registers a lane worktree whose registry entry was lost |
